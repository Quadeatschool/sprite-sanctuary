# Sprite Sanctuary

A pixel pet that lives on your desktop and shows, by its mood alone, whether you're doing what you planned right now.

**Download:** [latest release](https://github.com/Quadeatschool/sprite-sanctuary/releases/latest) · **Website:** https://quadeatschool.github.io/sprite-sanctuary/

This repository holds the website, the installers (under Releases) and the public issue tracker. The app's source code is kept elsewhere.

Found a problem? [Open an issue](https://github.com/Quadeatschool/sprite-sanctuary/issues). Don't post personal details; issues are public.
